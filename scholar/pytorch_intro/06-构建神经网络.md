# 构建神经网络

> 本章目标：掌握 `torch.nn.Module` 的组织方式，能够用层和容器搭建网络、查看参数、切换训练 / 推理模式，并理解 logits 与概率的区别。

官方教程：[Build the Neural Network](https://pytorch.org/tutorials/beginner/basics/buildmodel_tutorial.html) · [torch.nn API](https://pytorch.org/docs/stable/nn.html)

## 1. `nn.Module`：一切模型的基类

PyTorch 中所有神经网络模块都继承自 `nn.Module`。一个模型本身也是一个模块，可以包含其他模块（层），形成树状结构。

```python
import torch
from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()                 # 必须先调用
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
        )

    def forward(self, x):
        x = self.flatten(x)                # [N, 1, 28, 28] → [N, 784]
        logits = self.linear_relu_stack(x) # [N, 784] → [N, 10]
        return logits
```

两个核心方法：

| 方法 | 职责 |
| --- | --- |
| `__init__` | 声明层和可学习参数 |
| `forward` | 描述数据如何流经这些层 |

在 `__init__` 中赋值的 `nn.Module` 会自动注册为子模块，不需要手动维护参数列表。

## 2. 选择设备并移动模型

```python
device = (
    torch.accelerator.current_accelerator().type
    if torch.accelerator.is_available()
    else "cpu"
)
print(f"Using {device} device")

model = NeuralNetwork().to(device)
```

`model.to(device)` 会原地移动模型的所有参数和缓冲区，并返回模型本身。

> 模型和数据必须在同一设备上。每次把批次送入模型前，记得 `X = X.to(device)`。

## 3. 不要直接调用 `forward`

```python
y = model(x)          # 正确
# y = model.forward(x)  # 不推荐
```

`model(x)` 会调用 `__call__`，其中除了 `forward`，还会处理钩子（hooks）等机制。直接调用 `forward` 会绕过这些机制。

## 4. 逐层理解示例模型

以 3 张 28×28 的图像为例：

```python
input_image = torch.rand(3, 28, 28)   # [N, H, W]
```

### 4.1 `nn.Flatten`

把每个样本展平成一维，保留批次维：

```python
flatten = nn.Flatten()
flat_image = flatten(input_image)     # [3, 784]
```

`nn.Flatten(start_dim=1, end_dim=-1)` 默认从第 1 维展平到最后一维。

### 4.2 `nn.Linear`

线性变换：

```text
y = x @ W.T + b
```

```python
layer1 = nn.Linear(in_features=28 * 28, out_features=20)
hidden1 = layer1(flat_image)          # [3, 20]
```

参数形状：

- `weight`: `[out_features, in_features]`，即 `[20, 784]`
- `bias`: `[out_features]`，即 `[20]`

### 4.3 `nn.ReLU`

非线性激活函数：

```text
ReLU(x) = max(0, x)
```

```python
hidden1 = nn.ReLU()(hidden1)
```

没有非线性激活，多层线性层叠加仍然等价于一个线性层。

### 4.4 `nn.Sequential`

按顺序执行的容器：

```python
seq_modules = nn.Sequential(
    flatten,
    layer1,
    nn.ReLU(),
    nn.Linear(20, 10),
)
logits = seq_modules(input_image)
```

适合简单的线性结构；需要分支、残差连接时，直接在 `forward` 中写。

### 4.5 `nn.Softmax`

把 logits 转成概率：

```python
softmax = nn.Softmax(dim=1)
pred_probab = softmax(logits)          # 每行和为 1
y_pred = pred_probab.argmax(1)
```

`dim` 指定在哪一维上归一化。对于 `[N, C]` 的分类输出，`dim=1` 表示在类别维上归一化。

## 5. logits 与概率

| 名称 | 含义 | 范围 |
| --- | --- | --- |
| logits | 模型最后一层的原始输出 | `(-∞, +∞)` |
| probabilities | Softmax 后的概率 | `[0, 1]`，各类和为 1 |

关键规则：

- `nn.CrossEntropyLoss` 接收 **logits**，内部会做 `LogSoftmax + NLLLoss`；
- 所以模型输出 logits 即可，**不要**在损失函数前加 Softmax；
- 只有在推理、展示概率时才手动加 `Softmax`。

```python
logits = model(X)
pred_probab = nn.Softmax(dim=1)(logits)
y_pred = pred_probab.argmax(1)
```

## 6. 查看模型参数

`nn.Module` 会自动追踪所有注册的参数：

```python
print(model)

for name, param in model.named_parameters():
    print(f"{name:30s} {tuple(param.shape)}")

# 只要参数张量
params = list(model.parameters())
```

输出示例：

```text
linear_relu_stack.0.weight  (512, 784)
linear_relu_stack.0.bias    (512,)
linear_relu_stack.2.weight  (512, 512)
linear_relu_stack.2.bias    (512,)
linear_relu_stack.4.weight  (10, 512)
linear_relu_stack.4.bias    (10,)
```

常用方法：

| 方法 | 作用 |
| --- | --- |
| `parameters()` | 迭代所有可训练参数 |
| `named_parameters()` | 迭代 `(名字, 参数)` |
| `state_dict()` | 参数字典，用于保存 / 加载 |
| `buffers()` / `named_buffers()` | BatchNorm 运行均值等非参数状态 |
| `children()` / `modules()` | 遍历子模块 |

> 如果直接把参数写成普通 Python 列表（如 `self.layers = [nn.Linear(...), ...]`），它们不会被注册。需要容器时使用 `nn.ModuleList` 或 `nn.ModuleDict`。

## 7. 训练模式与评估模式

```python
model.train()   # 训练模式：Dropout 随机丢弃，BatchNorm 使用当前批次统计量
model.eval()    # 评估模式：Dropout 关闭，BatchNorm 使用运行统计量
```

| 模式 | Dropout | BatchNorm |
| --- | --- | --- |
| `train()` | 启用 | 使用批次统计量并更新运行统计 |
| `eval()` | 关闭 | 使用运行统计量，不更新 |

注意：

- `model.eval()` **不会**关闭梯度，推理时还应配合 `torch.no_grad()`；
- 训练循环每个 epoch 开始时调用 `model.train()`，评估前调用 `model.eval()`；
- 忘记 `eval()` 会导致推理结果不稳定。

## 8. 查看网络结构

简单方式：

```python
print(model)
```

更详细的方式（需要安装 `torchinfo`）：

```python
# pip install torchinfo
from torchinfo import summary

summary(model, input_size=(64, 1, 28, 28))
```

它会输出每一层的输入 / 输出形状、参数量等信息，非常适合排查形状问题。

## 9. 常用层速查

| 层 | 用途 | 关键参数 |
| --- | --- | --- |
| `nn.Linear` | 全连接 | `in_features`、`out_features`、`bias` |
| `nn.Conv2d` | 二维卷积 | `in_channels`、`out_channels`、`kernel_size`、`stride`、`padding` |
| `nn.MaxPool2d` | 最大池化 | `kernel_size`、`stride` |
| `nn.AdaptiveAvgPool2d` | 自适应平均池化 | `output_size` |
| `nn.BatchNorm2d` | 批归一化 | `num_features` |
| `nn.Dropout` | 随机丢弃 | `p` |
| `nn.Flatten` | 展平 | `start_dim`、`end_dim` |
| `nn.ReLU` / `nn.GELU` / `nn.Sigmoid` | 激活 | — |
| `nn.Embedding` | 词嵌入 | `num_embeddings`、`embedding_dim` |
| `nn.LSTM` / `nn.GRU` | 循环网络 | `input_size`、`hidden_size`、`num_layers` |

## 10. 参数初始化（进阶）

PyTorch 会为大多数层提供默认初始化。需要自定义时：

```python
def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.kaiming_normal_(m.weight, nonlinearity="relu")
        nn.init.zeros_(m.bias)

model.apply(init_weights)
```

常见初始化：`nn.init.xavier_uniform_`、`nn.init.kaiming_normal_`、`nn.init.zeros_`、`nn.init.constant_`。

## 常见坑

1. **忘记 `super().__init__()`**：子模块无法正确注册，后续参数访问会出问题。
2. **用普通 list 存子模块**：参数不会被注册；改用 `nn.ModuleList`。
3. **`Flatten` 维度写错**：默认保留第 0 维（批次），不要手动把批次也展平。
4. **在 `CrossEntropyLoss` 前加 Softmax**：重复归一化，损失和梯度错误。
5. **模型 / 数据设备不一致**：检查 `.to(device)` 是否同时作用于两者。
6. **推理前忘记 `model.eval()`**：Dropout / BatchNorm 行为错误。
7. **直接调用 `model.forward(x)`**：绕过 `__call__` 的钩子机制。
8. **输入形状与第一层不匹配**：用 `print(model)` 或 `torchinfo` 核对。

## 本章小结

- 模型 = 继承 `nn.Module` + 在 `__init__` 声明层 + 在 `forward` 描述数据流。
- `model(x)` 而不是 `model.forward(x)`。
- 分类模型输出 logits，`CrossEntropyLoss` 直接接收 logits。
- 训练前 `train()`，推理前 `eval()` + `no_grad()`。
- 用 `parameters()` / `named_parameters()` 管理参数，用 `state_dict()` 保存。

## 练习

1. 把示例模型改成卷积网络：`Conv2d → ReLU → MaxPool2d → Flatten → Linear`。
2. 用 `torchinfo.summary` 打印模型，核对每层输出形状。
3. 在模型中加一个 `nn.Dropout(0.5)`，分别用 `train()` 和 `eval()` 前向两次，观察输出差异。
