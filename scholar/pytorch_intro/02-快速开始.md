# 快速开始

> 本章目标：用一份可运行的代码走完“数据 → 模型 → 训练 → 评估 → 保存 → 推理”的完整流程。先建立整体感，细节留给后续章节。

官方教程：[Quickstart](https://pytorch.org/tutorials/beginner/basics/quickstart_tutorial.html)

## 1. 全流程一览

```text
FashionMNIST 数据集
      │  Dataset + DataLoader
      ▼
按批次取出 [N, 1, 28, 28] 的图像
      │  model(X)
      ▼
输出 [N, 10] 的 logits
      │  CrossEntropyLoss
      ▼
损失 → backward() → optimizer.step()
      │
      ▼
在测试集上评估 → 保存 state_dict → 加载并推理
```

## 2. 选择设备

```python
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import v2

device = (
    torch.accelerator.current_accelerator().type
    if torch.accelerator.is_available()
    else "cpu"
)
print(f"Using {device} device")
```

`torch.accelerator` 会自动选择当前可用的加速器（如 CUDA、MPS、XPU）。如果使用较旧版本，可写成：

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
```

## 3. 准备数据

```python
transform = v2.Compose([
    v2.ToImage(),                        # PIL 图像 → Image 张量
    v2.ToDtype(torch.float32, scale=True)  # 转为 float32，并缩放到 [0, 1]
])

training_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=transform,
)

test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=transform,
)

batch_size = 64
train_dataloader = DataLoader(training_data, batch_size=batch_size, shuffle=True)
test_dataloader = DataLoader(test_data, batch_size=batch_size)
```

一批数据的形状：

```text
X: [64, 1, 28, 28]   # [N, C, H, W]
y: [64]              # int64 类别索引
```

> 训练集需要 `shuffle=True` 打乱顺序；测试集不需要打乱。

## 4. 定义模型

```python
class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
        )

    def forward(self, x):
        x = self.flatten(x)              # [N, 1, 28, 28] → [N, 784]
        logits = self.linear_relu_stack(x)  # [N, 784] → [N, 10]
        return logits


model = NeuralNetwork().to(device)
print(model)
```

形状变化：

```text
[N, 1, 28, 28] --Flatten--> [N, 784] --Linear--> [N, 512]
               --ReLU--> [N, 512] --Linear--> [N, 512]
               --ReLU--> [N, 512] --Linear--> [N, 10]
```

最后一层输出 10 个 **logits**，分别对应 10 个类别，尚未经过 Softmax。

## 5. 损失函数与优化器

```python
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=1e-3)
```

- `CrossEntropyLoss` 内部包含 `LogSoftmax + NLLLoss`，所以模型输出 **不要** 先做 Softmax。
- `optimizer` 需要拿到所有待训练参数：`model.parameters()`。

## 6. 训练循环

```python
def train(dataloader, model, loss_fn, optimizer):
    size = len(dataloader.dataset)
    model.train()                        # 切换到训练模式

    for batch, (X, y) in enumerate(dataloader):
        X, y = X.to(device), y.to(device)

        # 1. 前向计算
        pred = model(X)
        loss = loss_fn(pred, y)

        # 2. 反向传播 + 更新参数
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

        if batch % 100 == 0:
            loss, current = loss.item(), (batch + 1) * len(X)
            print(f"loss: {loss:>7f} [{current:>5d}/{size:>5d}]")
```

五个动作的顺序：

```text
前向 → 损失 → backward → step → zero_grad
```

`zero_grad()` 也可以放在 `backward()` 之前，关键是**在下一批次反向传播前把上一批的梯度清零**。

## 7. 测试循环

```python
def test(dataloader, model, loss_fn):
    size = len(dataloader.dataset)
    num_batches = len(dataloader)
    model.eval()                         # 切换到评估模式

    test_loss, correct = 0, 0
    with torch.no_grad():                # 评估不需要梯度
        for X, y in dataloader:
            X, y = X.to(device), y.to(device)
            pred = model(X)
            test_loss += loss_fn(pred, y).item()
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()

    test_loss /= num_batches
    correct /= size
    print(f"Test Error: \n Accuracy: {(100*correct):>0.1f}%, Avg loss: {test_loss:>8f} \n")
```

要点：

- `model.eval()` 让 Dropout、BatchNorm 等层进入推理行为；
- `torch.no_grad()` 关闭梯度记录，减少显存 / 内存占用并加速；
- `pred.argmax(1)` 取每行最大 logit 的下标作为预测类别。

## 8. 开始训练

```python
epochs = 5
for t in range(epochs):
    print(f"Epoch {t+1}\n-------------------------------")
    train(train_dataloader, model, loss_fn, optimizer)
    test(test_dataloader, model, loss_fn)
print("Done!")
```

正常情况下会看到训练损失下降、测试准确率上升。5 个 epoch 后准确率大约在 65% 左右（受随机性影响）。

## 9. 保存、加载与推理

```python
# 保存参数
torch.save(model.state_dict(), "model.pth")

# 重新创建同结构模型，再加载参数
model = NeuralNetwork().to(device)
model.load_state_dict(torch.load("model.pth", weights_only=True))

# 推理
classes = [
    "T-shirt/top", "Trouser", "Pullover", "Dress", "Coat",
    "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot",
]

model.eval()
x, y = test_data[0][0], test_data[0][1]
with torch.no_grad():
    x = x.to(device)
    pred = model(x)
    predicted = classes[pred[0].argmax(0)]
    actual = classes[y]
    print(f'Predicted: "{predicted}", Actual: "{actual}"')
```

## 10. 关键 API 速查

| 环节 | API | 作用 |
| --- | --- | --- |
| 设备 | `torch.accelerator` / `Tensor.to(device)` | 选择并移动设备 |
| 数据 | `datasets.FashionMNIST` | 内置图像数据集 |
| 批处理 | `DataLoader(dataset, batch_size, shuffle)` | 按批次迭代 |
| 模型 | `nn.Module` + `forward` | 定义网络 |
| 损失 | `nn.CrossEntropyLoss` | 多分类交叉熵 |
| 优化 | `torch.optim.SGD` | 随机梯度下降 |
| 模式 | `model.train()` / `model.eval()` | 训练 / 推理行为 |
| 梯度 | `loss.backward()` / `zero_grad()` | 反向传播 / 清零 |
| 保存 | `state_dict()` / `torch.save` | 持久化参数 |

## 常见坑

1. **忘记 `.to(device)`**：模型在 GPU、数据在 CPU 时会报设备不一致。
2. **忘记 `zero_grad()`**：梯度跨批次累积，训练行为错误。
3. **评估时忘记 `model.eval()`**：Dropout / BatchNorm 仍按训练模式工作，结果不稳定。
4. **在 `CrossEntropyLoss` 前加 Softmax**：相当于重复归一化，损失和梯度都会出错。
5. **把测试集也 `shuffle=True`**：评估结果本身不受影响，但复现和调试更麻烦；测试集通常不打乱。
6. **用 `model.forward(x)` 代替 `model(x)`**：会绕过 `__call__` 中的钩子等机制，官方明确不建议。
