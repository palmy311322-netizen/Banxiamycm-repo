# 数据集与数据加载器

> 本章目标：理解 PyTorch 数据管道的两个核心抽象——`Dataset` 与 `DataLoader`，能够使用内置数据集、编写自定义数据集，并按批次高效读取数据。

官方教程：[Datasets & DataLoaders](https://pytorch.org/tutorials/beginner/basics/data_tutorial.html) · [torch.utils.data API](https://pytorch.org/docs/stable/data.html)

## 1. 为什么要拆成两层

训练代码不应该关心“图片存在哪个目录、标签怎么解析、如何拼成批次”。

```text
Dataset：负责“一条样本怎么读”      →  len(dataset)、dataset[i]
DataLoader：负责“一批样本怎么取”    →  批大小、打乱、并行、拼接
```

这种拆分让数据处理和模型训练解耦：换数据集时只改 `Dataset`，训练循环保持不变。

## 2. Dataset 协议

PyTorch 的 map-style 数据集需要实现三个方法：

| 方法 | 职责 |
| --- | --- |
| `__init__` | 初始化路径、标注文件、变换等 |
| `__len__` | 返回样本总数 |
| `__getitem__(idx)` | 返回第 `idx` 个样本（通常是 `(特征, 标签)`） |

实现后就可以像列表一样访问：

```python
sample = dataset[0]
print(len(dataset))
```

## 3. 使用内置数据集

以 `torchvision.datasets.FashionMNIST` 为例：

```python
import torch
from torchvision import datasets
from torchvision.transforms import v2

transform = v2.Compose([
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
])

training_data = datasets.FashionMNIST(
    root="data",          # 数据存放目录
    train=True,           # True=训练集，False=测试集
    download=True,        # 不存在时自动下载
    transform=transform,             # 作用于特征
    target_transform=None,           # 作用于标签
)

test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=transform,
)

print(len(training_data), len(test_data))   # 60000 10000
```

四个常用参数：

| 参数 | 含义 |
| --- | --- |
| `root` | 数据根目录 |
| `train` | 选择训练集还是测试集 |
| `download` | 本地不存在时是否下载 |
| `transform` / `target_transform` | 对特征 / 标签的变换 |

类似的内置数据集还有 CIFAR、ImageNet、COCO 等，完整列表见 [torchvision.datasets](https://pytorch.org/vision/stable/datasets.html)。

## 5. 编写自定义 Dataset

假设图像放在 `img_dir/`，标签记录在 `annotations_file`（CSV，每行是“文件名, 类别”）：

```python
import os
import pandas as pd
from torch.utils.data import Dataset
from torchvision.io import decode_image


class CustomImageDataset(Dataset):
    def __init__(self, annotations_file, img_dir, transform=None, target_transform=None):
        self.img_labels = pd.read_csv(annotations_file)
        self.img_dir = img_dir
        self.transform = transform
        self.target_transform = target_transform

    def __len__(self):
        return len(self.img_labels)

    def __getitem__(self, idx):
        img_path = os.path.join(self.img_dir, self.img_labels.iloc[idx, 0])
        image = decode_image(img_path)          # 读取为 [C, H, W] 的 uint8 张量
        label = self.img_labels.iloc[idx, 1]

        if self.transform:
            image = self.transform(image)
        if self.target_transform:
            label = self.target_transform(label)

        return image, label
```

关键约定：

- `__getitem__` 必须能对**任意合法索引**稳定返回一个样本；
- 返回顺序通常固定为 `(特征, 标签)`，DataLoader 会沿第 0 维自动拼成批次；
- 不要在这里做跨样本的全局统计（如数据集均值），那些应提前算好。

## 6. DataLoader：按批次读取

```python
from torch.utils.data import DataLoader

train_dataloader = DataLoader(
    training_data,
    batch_size=64,
    shuffle=True,
    num_workers=0,
)

test_dataloader = DataLoader(
    test_data,
    batch_size=64,
    shuffle=False,
)
```

迭代：

```python
train_features, train_labels = next(iter(train_dataloader))
print(train_features.shape)   # torch.Size([64, 1, 28, 28])
print(train_labels.shape)     # torch.Size([64])
print(train_labels.dtype)     # torch.int64
```

`DataLoader` 返回的是可迭代对象，每个元素是一个批次；`len(dataloader)` 是批次数：

```text
len(dataloader) = ceil(样本数 / batch_size)   # drop_last=False
```

## 7. DataLoader 常用参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `batch_size` | `1` | 每批样本数 |
| `shuffle` | `False` | 每个 epoch 是否打乱（训练集建议 `True`） |
| `num_workers` | `0` | 子进程数量；`0` 表示主进程加载 |
| `pin_memory` | `False` | 将批次放入锁页内存，加速 CPU→GPU 拷贝 |
| `drop_last` | `False` | 是否丢弃不足一个批次的尾部数据 |
| `sampler` | `None` | 自定义采样器，与 `shuffle` 互斥 |
| `collate_fn` | `None` | 自定义如何把样本列表拼成批次 |
| `persistent_workers` | `False` | epoch 之间是否保留 worker（需 `num_workers > 0`） |
| `prefetch_factor` | `2` | 每个 worker 预取的批次数（需 `num_workers > 0`） |
| `timeout` | `0` | 读取一个批次的最长等待秒数 |

性能建议：

- GPU 训练时可用 `num_workers=2~8`、`pin_memory=True`；
- worker 不是越多越好，过多会争抢 CPU / 内存；
- `collate_fn` 用于变长序列、检测框等无法直接堆叠的数据。

## 8. 划分训练集 / 验证集 / 测试集

常见做法：

```python
from torch.utils.data import random_split

train_set, val_set = random_split(
    training_data,
    [50000, 10000],
    generator=torch.Generator().manual_seed(42),
)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
val_loader = DataLoader(val_set, batch_size=64, shuffle=False)
test_loader = DataLoader(test_data, batch_size=64, shuffle=False)
```

职责区分：

| 集合 | 用途 | 是否参与梯度更新 |
| --- | --- | --- |
| 训练集 | 学习参数 | 是 |
| 验证集 | 调超参数、早停、选模型 | 否 |
| 测试集 | 最终评估泛化能力 | 否 |

不要用测试集反复调参，否则测试结果会偏乐观。

## 9. map-style 与 iterable-style

| 类型 | 特点 | 适用场景 |
| --- | --- | --- |
| map-style `Dataset` | 实现 `__len__` + `__getitem__`，可按索引随机访问 | 文件列表、内存数据 |
| `IterableDataset` | 实现 `__iter__`，只能顺序流式读取 | 日志流、超大文件、无法随机访问的数据 |

`IterableDataset` 与多进程配合时，需要自行处理各 worker 之间的数据分片，通常是读取分片后再用 `worker_info` 切分。

## 10. API 速查

| 用途 | API |
| --- | --- |
| 基类 | `torch.utils.data.Dataset`、`IterableDataset` |
| 加载器 | `torch.utils.data.DataLoader` |
| 划分 | `random_split`、`Subset` |
| 采样 | `SequentialSampler`、`RandomSampler`、`WeightedRandomSampler` |
| 拼接 | `default_collate`、自定义 `collate_fn` |
| 图像解码 | `torchvision.io.decode_image` |

## 常见坑

1. **Windows 上 `num_workers > 0` 报错 / 卡住**：多进程使用 `spawn`，训练脚本必须放在 `if __name__ == "__main__":` 下。
2. **测试集也 `shuffle=True`**：评估结果不变，但复现和可视化更麻烦；测试集通常不打乱。
3. **`num_workers` 过大**：频繁创建进程、占用大量内存，反而变慢。
4. **忘记 `pin_memory` 与 `non_blocking`**：GPU 训练时数据传输可能成为瓶颈，可配合 `X.to(device, non_blocking=True)`。
5. **最后一批不足 `batch_size`**：如果模型含 BatchNorm 等对批大小敏感的层，可考虑 `drop_last=True`。
6. **在 `__getitem__` 里做重计算**：每个 epoch 都会重复执行，昂贵的预处理应缓存或提前完成。
7. **自定义 Dataset 返回的标签 dtype 不对**：分类标签应为 `int64`，否则交叉熵可能报错。

## 本章小结

- `Dataset` 定义“一条样本怎么读”，`DataLoader` 定义“一批样本怎么取”。
- 自定义数据集只需实现 `__init__`、`__len__`、`__getitem__`。
- 训练集打乱并增强，验证 / 测试集使用确定性流程。
- 用 `num_workers`、`pin_memory` 等参数优化数据吞吐，但不要盲目调大。
