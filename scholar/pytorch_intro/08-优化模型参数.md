# 优化模型参数

> 本章目标：把数据、模型、自动微分串成完整的训练 / 评估循环，理解损失函数、优化器、超参数以及训练中的常见诊断方法。

官方教程：[Optimizing Model Parameters](https://pytorch.org/tutorials/beginner/basics/optimization_tutorial.html) · [torch.optim API](https://pytorch.org/docs/stable/optim.html) · [Loss Functions](https://pytorch.org/docs/stable/nn.html#loss-functions)

## 1. 训练在做什么

训练是一个迭代过程。每个 **epoch** 包含两部分：

| 阶段 | 数据 | 参数是否更新 | 目的 |
| --- | --- | --- | --- |
| 训练循环 | 训练集 | 是 | 让模型拟合数据 |
| 验证 / 测试循环 | 验证集 / 测试集 | 否 | 检查泛化能力 |

每个批次内部的核心五步：

```text
前向预测 → 计算损失 → 反向传播 → 更新参数 → 清零梯度
```

## 2. 前置代码

```python
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import v2

transform = v2.Compose([
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
])

training_data = datasets.FashionMNIST(
    root="data", train=True, download=True, transform=transform
)
test_data = datasets.FashionMNIST(
    root="data", train=False, download=True, transform=transform
)

train_dataloader = DataLoader(training_data, batch_size=64, shuffle=True)
test_dataloader = DataLoader(test_data, batch_size=64)

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
        )

    def forward(self, x):
        x = self.flatten(x)
        return self.linear_relu_stack(x)

model = NeuralNetwork()
```

## 3. 超参数

超参数是训练前人为设定、不由梯度学习的参数：

| 超参数 | 含义 | 常见起点 |
| --- | --- | --- |
| `epochs` | 遍历整个训练集的次数 | 5～50 |
| `batch_size` | 每次更新参数使用的样本数 | 32～256 |
| `learning_rate` | 每步参数更新的幅度 | 常见起点：`1e-3`～`1e-1`（SGD 偏大，Adam 偏小） |
| `weight_decay` | 权重衰减（L2 正则） | `1e-4`～`1e-2` |
| `momentum` | SGD 动量 | `0.9` |

```python
learning_rate = 1e-3
batch_size = 64
epochs = 5
```

学习率的影响：

- 太小：收敛慢，可能停在次优点；
- 太大：损失震荡、发散，甚至出现 `NaN`；
- 通常需要配合学习率调度器或手动调参。

## 4. 损失函数

损失函数衡量预测与真实标签的差距，是训练要最小化的目标。

| 损失函数 | 任务 | 输入要求 |
| --- | --- | --- |
| `nn.MSELoss` | 回归 | 预测与目标同形状浮点张量 |
| `nn.L1Loss` | 回归（对异常值更稳健） | 同上 |
| `nn.CrossEntropyLoss` | 多分类 | **logits** + `int64` 类别索引 |
| `nn.NLLLoss` | 多分类 | **log-probabilities** + 类别索引 |
| `nn.BCEWithLogitsLoss` | 二分类 / 多标签 | **logits** + 0/1 浮点目标 |
| `nn.BCELoss` | 二分类 | 已经过 Sigmoid 的概率 |

以多分类为例：

```python
loss_fn = nn.CrossEntropyLoss()
```

它等价于 `LogSoftmax` + `NLLLoss`，因此：

- 模型输出 **logits**，不要提前 Softmax；
- 标签是类别索引，形状 `[N]`，dtype `int64`。

## 5. 优化器

优化器根据梯度更新参数：

```python
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)
```

常用优化器：

| 优化器 | 特点 | 典型场景 |
| --- | --- | --- |
| `SGD` | 最基础；配合 `momentum` 常用 | CNN、需要精细调参 |
| `Adam` | 自适应学习率，收敛快 | 大多数任务的默认选择 |
| `AdamW` | Adam + 解耦权重衰减 | Transformer、现代网络 |
| `RMSprop` | 自适应学习率 | RNN、部分视觉任务 |
| `Adagrad` | 累积历史梯度 | 稀疏特征 |

示例：

```python
# SGD + 动量
optimizer = torch.optim.SGD(
    model.parameters(), lr=0.01, momentum=0.9, weight_decay=1e-4
)

# Adam
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# AdamW
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)
```

> 优化器只应该拿到需要训练的参数。冻结某些层时，可用
> `filter(lambda p: p.requires_grad, model.parameters())`。

## 6. 优化循环的三步

```python
optimizer.zero_grad()   # 1. 清零旧梯度
loss.backward()         # 2. 反向传播，计算新梯度
optimizer.step()        # 3. 根据梯度更新参数
```

为什么必须清零：PyTorch 的梯度默认**累加**，不清零会把多个批次的梯度混在一起。

也可以写成官方快速开始中的顺序：

```python
loss.backward()
optimizer.step()
optimizer.zero_grad()
```

两者等价，关键是保证**下一次 `backward()` 之前**梯度已经清零。团队内部保持一种写法即可。

## 7. 完整训练与测试循环

```python
def train_loop(dataloader, model, loss_fn, optimizer):
    size = len(dataloader.dataset)
    model.train()                       # 训练模式

    for batch, (X, y) in enumerate(dataloader):
        X, y = X.to(device), y.to(device)

        # 前向 + 损失
        pred = model(X)
        loss = loss_fn(pred, y)

        # 反向 + 更新
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        if batch % 100 == 0:
            loss, current = loss.item(), batch * len(X) + len(X)
            print(f"loss: {loss:>7f} [{current:>5d}/{size:>5d}]")


def test_loop(dataloader, model, loss_fn):
    model.eval()                        # 评估模式
    size = len(dataloader.dataset)
    num_batches = len(dataloader)
    test_loss, correct = 0, 0

    with torch.no_grad():               # 评估不需要梯度
        for X, y in dataloader:
            X, y = X.to(device), y.to(device)
            pred = model(X)
            test_loss += loss_fn(pred, y).item()
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()

    test_loss /= num_batches
    correct /= size
    print(f"Test Error: \n Accuracy: {(100*correct):>0.1f}%, Avg loss: {test_loss:>8f} \n")
```

运行：

```python
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)

for t in range(epochs):
    print(f"Epoch {t+1}\n-------------------------------")
    train_loop(train_dataloader, model, loss_fn, optimizer)
    test_loop(test_dataloader, model, loss_fn)
print("Done!")
```

### 评估指标的细节

- 准确率：`(pred.argmax(1) == y).float().sum() / 样本总数`；
- 平均损失：官方示例按批次数平均；如果最后一批不足 `batch_size`，更精确的做法是按样本数加权：

```python
test_loss += loss_fn(pred, y).item() * len(X)
# ...
test_loss /= size
```

- 分类任务还可以计算 precision、recall、F1、混淆矩阵。

## 8. `train()` 与 `eval()`

```python
model.train()   # 每个 epoch 训练前
model.eval()    # 每次评估前
```

| 模式 | Dropout | BatchNorm |
| --- | --- | --- |
| `train()` | 启用 | 使用当前批次统计量 |
| `eval()` | 关闭 | 使用运行统计量 |

`model.eval()` 只改变层的行为，**不会**关闭梯度；推理时还要加 `torch.no_grad()`。

## 9. 验证集与模型选择

不要只用训练集和测试集。标准做法是再划出验证集：

```python
from torch.utils.data import random_split

train_set, val_set = random_split(
    training_data,
    [50000, 10000],
    generator=torch.Generator().manual_seed(42),
)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
val_loader = DataLoader(val_set, batch_size=64)
test_loader = DataLoader(test_data, batch_size=64)
```

每个 epoch 后：

1. 在验证集上计算损失 / 准确率；
2. 保存验证指标最好的模型；
3. 训练结束后，只在测试集上评估一次。

```python
from copy import deepcopy

best_val_loss = float("inf")
best_state = None

for epoch in range(epochs):
    train_loop(train_loader, model, loss_fn, optimizer)
    val_loss = evaluate(val_loader, model, loss_fn)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        best_state = deepcopy(model.state_dict())   # 注意深拷贝

# 训练结束后恢复最佳参数
model.load_state_dict(best_state)
```

> 这里的 `evaluate` 可以复用上面 `test_loop` 的统计逻辑，只需返回平均验证损失而不打印。

> `model.state_dict()` 返回的是引用。如果只写 `best_state = model.state_dict()`，后续训练会继续修改同一份参数，所谓“最佳模型”也会被覆盖。

## 10. 学习率调度与梯度裁剪（进阶）

### 学习率调度

```python
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=10, gamma=0.1)

for epoch in range(epochs):
    train_loop(...)
    val_loss = evaluate(...)
    scheduler.step()        # 通常每个 epoch 调一次
```

常用调度器：`StepLR`、`CosineAnnealingLR`、`ReduceLROnPlateau`、`OneCycleLR`。
`OneCycleLR` 通常每个批次调用一次 `scheduler.step()`，以官方文档为准。

### 梯度裁剪

防止梯度爆炸，常用于 RNN / Transformer：

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
```

### 混合精度与编译（了解即可）

- 混合精度：`torch.amp.autocast` + `torch.amp.GradScaler`，减少显存并加速；
- 编译：`model = torch.compile(model)`，用编译优化前向 / 反向速度。

## 11. 复现性与梯度累积（进阶）

### 复现性

深度学习包含大量随机性（参数初始化、数据打乱、数据增强、Dropout）。需要可复现实验时：

```python
import random

import numpy as np
import torch

seed = 42
random.seed(seed)
np.random.seed(seed)
torch.manual_seed(seed)
torch.cuda.manual_seed_all(seed)

# 可选：强制使用确定性算法（可能降低性能）
# torch.use_deterministic_algorithms(True)
```

DataLoader 也可以固定随机源：

```python
g = torch.Generator().manual_seed(seed)
train_loader = DataLoader(train_set, batch_size=64, shuffle=True, generator=g)
```

完全确定性在 GPU 上不一定能保证，但固定种子能显著减少结果波动。

### 梯度累积

显存不足、无法使用大 batch 时，可以累积多个小批次的梯度再更新一次：

```python
accum_steps = 4
optimizer.zero_grad()

for step, (X, y) in enumerate(train_dataloader):
    X, y = X.to(device), y.to(device)
    pred = model(X)
    loss = loss_fn(pred, y) / accum_steps   # 保持梯度尺度
    loss.backward()

    if (step + 1) % accum_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

等效批大小 = `batch_size × accum_steps`。注意最后一个不完整的累积周期需要单独处理。

## 常见坑

1. **忘记 `zero_grad()`**：梯度累积，更新方向错误。
2. **忘记 `model.train()` / `model.eval()`**：Dropout、BatchNorm 行为不对。
3. **评估时忘记 `no_grad()`**：浪费显存和计算，甚至可能 OOM。
4. **分类任务用 `MSELoss`**：优化目标与任务不匹配。
5. **在 `CrossEntropyLoss` 前加 Softmax**：重复归一化。
6. **学习率过大**：损失震荡或变成 `NaN`；先从小学习率试起。
7. **只看训练损失**：过拟合时训练损失仍下降，应观察验证指标。
8. **用测试集调参**：测试结果会偏乐观，失去 unbiased 评估的意义。
9. **保存“最佳模型”时没深拷贝**：最终保存的是最后一轮参数。
10. **数据 / 模型设备不一致**：每个批次都要 `.to(device)`。

## 本章小结

- 训练循环 = 前向 → 损失 → 反向 → 更新 → 清零。
- 损失函数要与任务匹配，`CrossEntropyLoss` 直接接收 logits。
- 优化器管理参数更新；学习率是最关键的超参数之一。
- 训练用 `train()`，评估用 `eval()` + `no_grad()`。
- 用验证集选模型，测试集只做最终评估。

## 练习

1. 比较 SGD（`lr=1e-3`）与 Adam（`lr=1e-3`）在 FashionMNIST 上 5 个 epoch 的收敛曲线。
2. 加入验证集，记录每个 epoch 的训练 / 验证损失，判断是否过拟合。
3. 使用 `StepLR`，观察学习率下降后验证准确率的变化。
4. 故意把学习率设为 `1.0`，观察损失如何变化，并解释原因。
