# 入门介绍

> 本章目标：先建立“训练一个模型到底在做什么”的全局地图，再进入具体 API。

官方教程：[Learn the Basics — Introduction](https://pytorch.org/tutorials/beginner/basics/intro.html)

## 1. PyTorch 是什么

PyTorch 是一个面向深度学习的开源框架，核心能力可以概括为四层：

| 层次 | 作用 | 代表 API |
| --- | --- | --- |
| 张量计算 | 类似 NumPy 的多维数组，可运行在 CPU / GPU 等设备上 | `torch.tensor`、`Tensor.to` |
| 自动微分 | 记录运算图，自动计算梯度 | `torch.autograd`、`backward()` |
| 神经网络 | 提供层、损失函数、优化器等积木 | `torch.nn`、`torch.optim` |
| 数据与生态 | 数据集、数据加载、视觉 / 文本 / 音频工具 | `torch.utils.data`、`torchvision` |

与 NumPy 的主要区别：

- 可以使用 GPU / MPS / XPU 等加速器；
- 支持自动微分，适合训练神经网络；
- 采用**动态计算图**：每次前向传播都会重新构建计算图，因此可以在模型里使用普通的 Python 控制流（`if`、`for`、变长输入等）。

## 2. 一次完整的机器学习流程

官方教程用 FashionMNIST 图像分类贯穿始终，把流程拆成七个环节：

| 步骤 | 要解决的问题 | 对应章节 |
| --- | --- | --- |
| 1. 准备数据 | 数据放在哪、如何读、如何预处理 | [04 数据集与数据加载器](./04-数据集与数据加载器.md)、[05 变换](./05-变换.md) |
| 2. 定义模型 | 如何把输入映射为输出 | [06 构建神经网络](./06-构建神经网络.md) |
| 3. 计算预测与损失 | 预测有多接近真实标签 | [08 优化模型参数](./08-优化模型参数.md) |
| 4. 反向传播 | 每个参数对损失的影响有多大 | [07 自动微分](./07-自动微分.md) |
| 5. 更新参数 | 沿梯度方向调整参数 | [08 优化模型参数](./08-优化模型参数.md) |
| 6. 评估模型 | 在未见过的数据上表现如何 | [08 优化模型参数](./08-优化模型参数.md) |
| 7. 保存模型 | 如何复用训练结果 | [09 保存与加载模型](./09-保存与加载模型.md) |

其中第 3～5 步会在训练循环中反复执行，是最核心的闭环：

```text
pred = model(X)              # 前向：得到预测
loss = loss_fn(pred, y)      # 损失：衡量预测与标签的差距
loss.backward()              # 反向：计算每个参数的梯度
optimizer.step()             # 更新：按梯度调整参数
optimizer.zero_grad()        # 清零：为下一批次做准备
```

## 3. 本教程使用的数据集

FashionMNIST 是一个替代手写数字 MNIST 的服装图像分类数据集：

- 训练集 60,000 张，测试集 10,000 张；
- 每张是 28×28 的灰度图；
- 共 10 个类别：T-shirt/top、Trouser、Pullover、Dress、Coat、Sandal、Shirt、Sneaker、Bag、Ankle boot；
- 单通道，因此输入形状为 `[N, 1, 28, 28]`。

它足够小，可以在普通 CPU 上几分钟跑完，适合用来理解流程。

## 5. 学习时先抓住这三件事

1. **形状**：每个张量的形状是什么？经过每一层后如何变化？大多数报错都来自形状或设备不匹配。
2. **设备**：数据和模型必须在同一个设备上；默认张量在 CPU 上，需要显式 `.to(device)`。
3. **梯度生命周期**：梯度会累积，所以每个批次更新前要清零；推理时用 `torch.no_grad()` 关闭梯度记录。

## 6. PyTorch 生态速览

| 库 | 用途 |
| --- | --- |
| `torchvision` | 图像数据集、模型、图像变换 |
| `torchaudio` | 音频数据集、特征提取、音频变换 |
| `torchtext` | 文本数据集与文本处理（维护状态以官方为准） |
| `torchdata` | 更灵活的数据加载与数据管道 |
| `torch.compile` | 编译模型以提升执行速度 |
| `torch.export` | 导出可部署的计算图 |

初学阶段只需要 `torch` 与 `torchvision`，其余按需了解。

## 本章小结

- PyTorch = 张量 + 自动微分 + 神经网络模块 + 数据工具。
- 训练流程是“数据 → 模型 → 损失 → 梯度 → 更新 → 评估 → 保存”。
- 后续每一章都在展开这条流程中的一块。
