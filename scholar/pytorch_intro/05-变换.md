# 变换

> 本章目标：掌握 `torchvision.transforms.v2` 的常用变换，能够为训练集和测试集搭建正确的预处理 / 数据增强流水线。

官方教程：[Transforms](https://pytorch.org/tutorials/beginner/basics/transforms_tutorial.html) · [torchvision.transforms.v2 API](https://pytorch.org/vision/stable/transforms.html)

## 1. 变换解决什么问题

原始数据通常不能直接喂给模型：

- 图像是 PIL 格式或 `uint8` 像素值，模型需要浮点张量；
- 像素范围是 `[0, 255]`，模型通常需要 `[0, 1]` 或标准化后的分布；
- 标签可能是整数、字符串或 one-hot；
- 训练时还需要随机裁剪、翻转等数据增强。

`transform` 负责特征，`target_transform` 负责标签：

```python
dataset = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=train_transform,        # 作用于图像
    target_transform=target_transform, # 作用于标签
)
```

这两个参数接受任意可调用对象（callable），包括 `v2.Compose` 组合出的流水线。

## 2. v2 的基本流水线

当前官方教程推荐 `torchvision.transforms.v2`：

```python
import torch
from torchvision.transforms import v2

transform = v2.Compose([
    v2.ToImage(),                                  # PIL / ndarray → Image 张量
    v2.ToDtype(torch.float32, scale=True),         # uint8 → float32，并缩放到 [0, 1]
])
```

### 2.1 `ToImage`

- 输入：PIL Image 或 NumPy `ndarray`；
- 输出：`torchvision.tv_tensors.Image`，保留原 dtype（通常是 `uint8`），形状为 `[C, H, W]`。

### 2.2 `ToDtype`

```python
v2.ToDtype(torch.float32, scale=True)
```

- `dtype=torch.float32`：转换为 float32；
- `scale=True`：把整数范围（如 `[0, 255]`）线性缩放到浮点范围 `[0.0, 1.0]`。

### 2.3 与传统 `ToTensor` 的关系

旧版常用：

```python
from torchvision import transforms

transform = transforms.ToTensor()   # 一步完成转张量 + 缩放
```

`v2` 把这两件事拆成 `ToImage()` 和 `ToDtype(scale=True)`，语义更清晰，也更容易组合。新代码建议使用 `v2`。

> 不要在同一条流水线里混用 `transforms.ToTensor()` 和 `v2.ToDtype(scale=True)`，否则可能被重复缩放。

## 3. 常用变换

### 3.1 几何变换

| 变换 | 作用 |
| --- | --- |
| `v2.Resize(size)` | 调整大小 |
| `v2.CenterCrop(size)` | 中心裁剪 |
| `v2.RandomCrop(size, padding=...)` | 随机裁剪 |
| `v2.RandomResizedCrop(size)` | 随机裁剪并缩放（常用增强） |
| `v2.RandomHorizontalFlip(p=0.5)` | 随机水平翻转 |
| `v2.RandomRotation(degrees=15)` | 随机旋转 |
| `v2.RandomAffine(...)` | 仿射变换 |

### 3.2 颜色变换

| 变换 | 作用 |
| --- | --- |
| `v2.ColorJitter(brightness, contrast, saturation, hue)` | 随机颜色扰动 |
| `v2.GaussianBlur(kernel_size, sigma)` | 高斯模糊 |
| `v2.RandomGrayscale(p=0.1)` | 随机转灰度 |
| `v2.Normalize(mean, std)` | 标准化 |

### 3.3 格式与组合

| 变换 | 作用 |
| --- | --- |
| `v2.ToImage()` | 转为图像张量 |
| `v2.ToDtype(dtype, scale)` | 转换数据类型 / 缩放 |
| `v2.Compose([...])` | 按顺序组合多个变换 |
| `v2.Lambda(fn)` | 包装任意函数 |
| `v2.Identity()` | 不做任何处理 |

## 4. 标准化

`Normalize` 对每个通道执行：

```text
output[c] = (input[c] - mean[c]) / std[c]
```

示例（RGB 三通道，ImageNet 常用统计量）：

```python
v2.Normalize(
    mean=[0.485, 0.456, 0.406],
    std=[0.229, 0.224, 0.225],
)
```

注意：

- 必须在 `ToDtype(..., scale=True)` **之后** 使用，否则输入还不是 `[0, 1]` 浮点值；
- `mean` / `std` 的长度要与通道数一致；
- 灰度图使用长度为 1 的序列，例如 `mean=[0.5], std=[0.5]`。

## 5. 训练与测试使用不同流水线

训练集需要随机增强，测试集必须确定性：

```python
train_transform = v2.Compose([
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
    v2.RandomResizedCrop(224, antialias=True),
    v2.RandomHorizontalFlip(p=0.5),
    v2.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.05),
    v2.Normalize(mean=[0.485, 0.456, 0.406],
                 std=[0.229, 0.224, 0.225]),
])

test_transform = v2.Compose([
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
    v2.Resize(256, antialias=True),
    v2.CenterCrop(224),
    v2.Normalize(mean=[0.485, 0.456, 0.406],
                 std=[0.229, 0.224, 0.225]),
])
```

原则：

- **训练集**：可以随机、可以增强，目的是提升泛化；
- **验证 / 测试集**：只做确定性变换，保证每次评估结果可比；
- 增强不要改变标签语义（例如数字分类中不要随意水平翻转，除非任务允许）。

## 6. 对标签做变换

用 `v2.Lambda` 包装任意函数。例如把整数标签转成 one-hot：

```python
import torch.nn.functional as F

target_transform = v2.Lambda(
    lambda y: F.one_hot(torch.tensor(y), num_classes=10).float()
)
```

> 注意：`nn.CrossEntropyLoss` 默认接收**类别索引**（`int64`），不是 one-hot。这个例子主要用于演示 `target_transform` 的用法；真正训练时是否使用 one-hot 取决于你选择的损失函数。

## 7. 自定义变换

`v2` 的变换本质上是 `nn.Module`，所以可以自己写一个：

```python
import torch
from torch import nn

class AddGaussianNoise(nn.Module):
    def __init__(self, std=0.05):
        super().__init__()
        self.std = std

    def forward(self, x):
        return x + torch.randn_like(x) * self.std


transform = v2.Compose([
    v2.ToImage(),
    v2.ToDtype(torch.float32, scale=True),
    AddGaussianNoise(std=0.02),
])
```

也可以直接传入普通函数 / lambda：

```python
v2.Lambda(lambda x: x.clamp(0, 1))
```

## 8. v2 的额外能力

- **支持 batch**：`v2` 变换可以直接作用在 `[N, C, H, W]` 的批次上；
- **支持 GPU**：变换是普通模块，可以先把数据搬到 GPU 再执行（需确认具体变换的支持情况）；
- **支持检测 / 分割**：`tv_tensors` 会同步变换图像、边界框和掩码。

初学阶段先把单样本流水线用熟即可。

## 9. API 速查

| 用途 | API |
| --- | --- |
| 组合 | `v2.Compose` |
| 格式 | `v2.ToImage`、`v2.ToDtype`、`v2.ToTensor`（旧） |
| 几何 | `Resize`、`CenterCrop`、`RandomCrop`、`RandomResizedCrop`、`RandomHorizontalFlip`、`RandomRotation` |
| 颜色 | `ColorJitter`、`GaussianBlur`、`RandomGrayscale`、`Normalize` |
| 自定义 | `v2.Lambda`、继承 `nn.Module` |

## 常见坑

1. **先 `Normalize` 后缩放**：标准化基于错误的数值范围，模型表现会明显异常。
2. **`mean` / `std` 顺序或长度错误**：RGB 顺序是 `(R, G, B)`，长度必须等于通道数。
3. **对测试集使用随机增强**：评估结果不可复现，且与真实部署不一致。
4. **混用旧版 `ToTensor` 与 v2 的缩放**：可能把 `[0, 1]` 再缩一次。
5. **以为 `transform` 会作用于整个批次**：数据集层面是逐样本调用；批处理发生在 DataLoader 的 `collate` 阶段。
6. **one-hot 标签配 `CrossEntropyLoss`**：形状和语义不匹配，应使用类别索引或改用相应损失函数。
7. **增强过强**：训练分布被破坏，损失下降但验证效果变差。

## 本章小结

- `transform` 处理特征，`target_transform` 处理标签。
- 推荐 `v2.Compose([ToImage(), ToDtype(float32, scale=True), ...])`。
- 训练用随机增强，测试用确定性预处理。
- `Normalize` 必须在缩放之后，参数按通道给出。

## 练习

1. 为 FashionMNIST 写两套流水线：训练集加随机水平翻转和随机裁剪，测试集只做缩放与标准化。
2. 用 `v2.Lambda` 把标签转成 one-hot，并打印一个样本验证形状。
3. 写一个自定义变换，把图像随机遮挡一块区域（Cutout），观察对训练的影响。
