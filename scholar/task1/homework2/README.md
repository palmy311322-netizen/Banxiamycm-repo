##**代码介绍**  
我在古登堡计划的语料库里面找了随便找了一篇，节选了一些存进了这个curpos.txt里面。  
然后AI生成了一个停用词表存进了stopwords.txt里面。  
运行之后，生成了一个result.csv，目测起来没有什么问题。  
这个模块里面的一些函数如下
|序号|函数名|功能|
|:---:|:---:|:---:|
|1|my_split(text)|将长字符串按要求处理，读入列表中|
|2|freq_count(words)|统计词频，存入字典中|
|3|quick_sort(lst)|快速排序，但是是元素为元组的列表，用于辅助4实现|
|4|quick_sort_dict(dict)|将字典转化为元素为元组的列表，再调用3|
|5|pure_dict(stopwords,dict)|删除原字典中所有的键为停止词的元素|
|6|bigram_count(words)|求出所有的二元词组，存进列表里|
*特别想说一下这里的4啊*，我真的不知道这个字典咋排序，所以稍微咨询了一下智慧的AI  

主函数的话，主要实现四个功能嘛：  
输出词频前20；  
输出纯净词频前20；  
输出二元词组频率前20；  
把相应的词和词频全部存入result.csv中  
##**思考题**  
两层循环多慢啊，假设总共有n个词，每次有m个词是已有的，那两层遍历下来，时间复杂度就是O(mn)≈O(n^2)；  
字典想要找到一个词，只要计算一次Hash就行了，时间复杂度是O(1)，那全部统计完，时间复杂度也只有O(n)；  
所以肯定是字典统计词频快啊。
