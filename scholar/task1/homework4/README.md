###matrix.py
1. 创建零矩阵和单位矩阵略。  
这里说的这个经典陷阱,主要原因如下：  
[0]*3得到的确实是[0,0,0]，  
但是，([0]*3)*3得到的却还是[0,0,0]。  
背后的原因是，py里面列表存储的不是值（不仅是列表，还有字典），而是指向对象的引用。  
在[0]*3中啊，这个虽然说也是复制的是引用，这个每个被复制出来的0，都指向同一个0，但是，这里0是不变的，所以无所谓；  
([0]*3)*3就不行了，它复制的引用指向第一行这个，第一行变了，其他的所有都跟着变，所以就会完蛋。  
2. 矩阵加减略。  
3. 矩阵乘法，需要三层循环。  
4. 矩阵转置。方法一很好理解。方法二，使用zip，确实写起来更容易（也查了一下，运行起来也会更快一些一点）。  
5. 求行列式的值。区别于矩阵，这里必须判定是否为方阵。然后就是递归，不断求代数余子式。
6. 这个有点意思。以前用cpp写过上面的五种矩阵基本操作，但是从来没写过这个求逆矩阵的。  
另外，我们学线性代数这门课的时候，似乎没有听过什么是高斯-约当法。后来查了一下，这种方法好像是书上教的，不过书上管这个叫初等行变换法。

####copy_test.py
这个主要就是一个测试文件，没有需要介绍的代码。  
在这里回答提出的问题：  
1. 方法一，引用赋值。修改B，就是修改了A。
2. 方法二，浅拷贝。B虽然是一个新的列表，但是内部元素仍然引用的是A的子列表，修改B，仍然会修改A。
3. 方法三，深拷贝。B终于完全独立了！  
为什么inverse(A)中必须使用深拷贝呢？这是明显的，不用深拷贝的话，对aug矩阵进行操作，肯定会破坏原本的A矩阵，这是我们不想看到的。
*这里突然想到*，在matrix.py里面，我没有调包用深拷贝，但是我手动逐元素复制来构造的，所以也能达到目的。
