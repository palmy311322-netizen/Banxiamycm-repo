# BP（反向传播）神经网络算法介绍

## 算法概述

BP（Back Propagation）算法是多层前馈神经网络中最经典的学习算法，由 Rumelhart、Hinton 和 McClelland 于 1986 年在 Nature 上发表的论文中系统提出。它是一种基于梯度下降策略的迭代学习算法，通过链式法则将输出层的误差反向逐层传递，从而计算每一层参数（权重和阈值）的梯度并进行更新。本实现严格参照周志华《机器学习》（西瓜书）第 5 章的符号系统和公式推导，是我手写的第一个神经网络代码。

## 核心原理

BP 算法的核心思想是**链式法则（Chain Rule）**与**梯度下降（Gradient Descent）**的结合：

1. **前向传播**：输入信号从输入层经过隐藏层逐层计算，最终到达输出层产生预测值。
2. **误差反向传播**：将输出层的预测误差，通过链式法则从后往前逐层传递，计算出每一层每个神经元对总误差的"贡献度"（即梯度）。
3. **参数更新**：利用计算出的梯度，沿负梯度方向调整权重和阈值，使损失函数逐步减小。

本实现采用西瓜书中的符号体系：
- 隐藏层激活函数和输出层激活函数均为 **Sigmoid** 函数
- 损失函数采用**均方误差（MSE）**
- 输出层梯度项 $g_j$ 和隐藏层梯度项 $e_h$ 自带负号，因此参数更新使用**加法**

本实现采用模块化设计，将纯数学计算与网络逻辑分离，分为两个文件：

### bp_network.py（网络模块）

封装了 `BPNeuralNetwork` 类，负责管理网络结构和训练流程：

| 方法名 | 功能 |
|---|---|
| `__init__(d, q, l)` | 初始化网络结构，随机初始化权重和阈值 |
| `forward(X)` | 前向传播，计算隐藏层输出 $b$ 和输出层预测值 $\hat{y}$ |
| `compute_loss(y)` | 调用计算模块，返回均方误差损失 |
| `backward(X, y)` | 反向传播，计算各参数的梯度更新量 |
| `train_step(X, y)` | 执行一次完整的前向→损失→反向→更新 |
| `train(X, y, epochs)` | 训练循环，迭代执行 `train_step` |
| `predict(X)` | 对输入数据进行二分类预测 |

## 算法步骤

1. **初始化**：随机初始化权重 $v$、$w$ 和阈值 $\gamma$、$\theta$（使用较小的随机值）
2. **前向传播**：输入样本 $x$，逐层计算 $\alpha_h \rightarrow b_h \rightarrow \beta_j \rightarrow \hat{y}_j$
3. **计算损失**：使用均方误差 $E = \frac{1}{2m}\sum(\hat{y} - y)^2$ 衡量预测值与真实值的差距
4. **反向传播**：
   - 计算输出层梯度项 $g_j = \hat{y}_j(1-\hat{y}_j)(y_j - \hat{y}_j)$
   - 计算隐藏层梯度项 $e_h = b_h(1-b_h)\sum w_{hj}g_j$
   - 计算各参数的更新量 $\Delta w$、$\Delta \theta$、$\Delta v$、$\Delta \gamma$
5. **参数更新**：沿负梯度方向更新 $w \leftarrow w + \eta \cdot \Delta w$（西瓜书符号体系下为加法）
6. **迭代终止**：重复步骤 2-5，直到达到预设迭代次数或损失收敛

## 算法特点

### 优点

- 能够学习非线性映射关系，理论上可以逼近任意连续函数（万能近似定理）
- 算法框架清晰，模块化设计便于理解和扩展
- 是深度学习的基础，理解了 BP 就理解了现代神经网络的核心

### 局限性

- 容易陷入局部最小值，无法保证找到全局最优解
- 训练速度较慢，尤其是网络层数较深时存在梯度消失问题（Sigmoid 在两端导数趋近于 0）
- 超参数敏感：学习率、隐藏层神经元个数等需要反复调参
- 过拟合风险：在训练数据上表现好，但泛化能力可能不足

## 应用场景

BP 神经网络适用于以下场景：

- 非线性分类和回归问题
- 模式识别、图像分类（浅层网络）
- 作为教学示例理解神经网络的前向传播与反向传播机制
- 为后续学习深度学习框架（如 PyTorch、TensorFlow）打下理论基础

## 扩展方向

单隐层 BP 网络的局限性催生了后续的改进与扩展：

- **多层网络（Deep Network）**：增加隐藏层数量，提升拟合能力，但需要解决梯度消失问题
- **ReLU 激活函数**：替代 Sigmoid，缓解梯度消失，加速训练收敛
- **交叉熵损失函数**：替代 MSE，配合 Sigmoid/Softmax 输出层，梯度更稳定
- **优化器改进**：从基础梯度下降发展出 SGD with Momentum、Adam、AdaGrad 等
- **正则化技术**：Dropout、L2 正则化等，防止过拟合

## 总结

BP 算法虽然诞生于上世纪 80 年代，但它所确立的"前向传播→计算误差→反向传播→参数更新"的范式，至今仍是所有深度学习框架的核心运行机制。通过手写单隐层 BP 网络，可以深入理解矩阵维度的对齐、链式法则的应用以及模块化代码设计的思想，是通往深度学习的重要基石。
