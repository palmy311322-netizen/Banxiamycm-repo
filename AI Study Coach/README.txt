================================================================================
                    每日学习督促助手 - 功能介绍文档
================================================================================

【项目简介】

这是一个本地运行的 CLI 学习督促工具，通过 AI 辅助生成每日学习计划，结合
Windows 系统通知和定时提醒，帮助用户保持学习节奏，养成持续学习的习惯。

核心理念：设定目标 → AI 规划 → 定时提醒 → 打卡记录 → 连续激励


================================================================================
                            核心功能
================================================================================

1. 多目标并行管理
   - 可同时设定多个学习目标（如"背单词"、"刷算法"、"做专业课的作业"）
   - 每个目标独立统计连续打卡天数
   - 支持目标归档，保持界面整洁

2. 任务清单管理
   - 为每个目标定义具体任务（如"每天背 30 个新词"）
   - 记录任务完成次数，追踪长期进度

3. AI 智能规划
   - 根据历史打卡记录和当前 streak，生成个性化每日计划
   - 幽默吐槽型督促语，让学习不那么枯燥
   - 动态调整任务优先级（完成少的优先推荐）

4. 打卡记录
   - 记录每次学习的内容笔记和时长
   - 支持快速打卡（一键标记所有任务完成）
   - 自动计算连续打卡天数

5. 状态统计
   - 显示今日进度和总体 streak
   - 各目标独立统计连续打卡情况
   - 可视化展示学习轨迹

6. AI 学习报告
   - 生成过去 N 天的学习总结
   - 指出亮点和不足
   - 给出下一步建议

7. Windows 系统通知
   - 定时弹窗提醒学习
   - 幽默督促语，根据 streak 动态调整语气
   - 支持自定义提醒时间

8. 定时任务
   - 自动注册 Windows 任务计划程序
   - 每天固定时间发送提醒
   - 一键设置/移除


================================================================================
                          模块架构说明
================================================================================

项目采用模块化设计，现将各模块的设计架构展示如下：

┌─────────────────────────────────────────────────────────────────────────────┐
│  main.py - 程序入口                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - 程序启动入口
    - 初始化 CLI 环境
    - 调用 helper.cli.main() 处理命令

  使用方式：
    python main.py <command> [options]


┌─────────────────────────────────────────────────────────────────────────────┐
│  helper/cli.py - 命令行界面模块                                              │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - 解析命令行参数（使用 argparse）
    - 定义所有子命令：goal, task, plan, checkin, status, report, notify, config
    - 调用数据库和 AI 模块执行具体操作
    - 使用 rich 库美化终端输出（表格、面板、颜色）

  主要函数：
    - cmd_goal()      : 目标管理（add/list/archive）
    - cmd_task()      : 任务管理（add/list）
    - cmd_plan()      : 每日计划（today/show/edit）
    - cmd_checkin()   : 打卡记录（single/quick）
    - cmd_status()    : 状态统计
    - cmd_report()    : AI 学习报告
    - cmd_notify()    : 通知管理（test/setup/remove/send）
    - cmd_config()    : 配置管理（show/set）

  依赖：
    - argparse（标准库）
    - rich（第三方库，终端美化）


┌─────────────────────────────────────────────────────────────────────────────┐
│  helper/db.py - 数据库模块                                                   │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - SQLite 数据库初始化和管理
    - 定义数据表结构：goals, tasks, daily_plans, checkins
    - 提供 CRUD 操作接口
    - 计算连续打卡天数（streak）

  数据表：
    1. goals（学习目标）
       - id, name, description, created_at, active

    2. tasks（任务清单）
       - id, goal_id, title, frequency, completed_count, created_at

    3. daily_plans（每日计划）
       - id, plan_date, tasks_json, ai_suggestion, created_at

    4. checkins（打卡记录）
       - id, plan_date, task_id, note, duration_minutes, checked_at

  主要函数：
    - init_db()              : 初始化数据库表结构
    - add_goal()             : 添加目标
    - list_goals()           : 列出目标
    - add_task()             : 添加任务
    - list_tasks()           : 列出任务
    - save_daily_plan()      : 保存每日计划
    - get_daily_plan()       : 获取每日计划
    - add_checkin()          : 添加打卡记录
    - get_checkins_for_date(): 获取某天的打卡
    - get_streak_for_goal()  : 计算目标连续天数
    - get_overall_streak()   : 计算总体连续天数

  依赖：
    - sqlite3（标准库）
    - json（标准库）


┌─────────────────────────────────────────────────────────────────────────────┐
│  helper/ai.py - AI 集成模块                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - 加载配置文件（config.toml）
    - 创建 Anthropic 兼容 API 客户端
    - 调用 AI 生成每日计划
    - 调用 AI 生成幽默督促语
    - 调用 AI 生成学习报告
    - 解析 AI 返回的 JSON 数据

  主要函数：
    - load_config()          : 加载 config.toml 配置
    - get_client()           : 创建 Anthropic 客户端
    - get_model()            : 获取配置的模型名称
    - _extract_json()        : 从 AI 响应中提取 JSON
    - generate_daily_plan()  : 生成今日计划（核心功能）
    - generate_motivation()  : 生成幽默督促语
    - generate_report()      : 生成学习报告

  设计要点：
    - 支持任意 Anthropic 兼容端点（百炼、Kimi、DeepSeek 等）
    - 使用基础 messages.create() 接口，避免新特性参数导致兼容性问题
    - AI 返回 JSON，用正则表达式提取，兼容 markdown 代码块

  依赖：
    - anthropic（第三方库）
    - tomllib（标准库，Python 3.11+）


┌─────────────────────────────────────────────────────────────────────────────┐
│  helper/notify.py - 通知模块                                                 │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - 发送 Windows 系统通知（toast 弹窗）
    - 支持多种通知方案：winotify → print 降级
    - 跨平台兼容（非 Windows 系统降级到 print）

  主要函数：
    - send_toast(title, message) : 发送系统通知

  实现方案：
    1. 优先使用 winotify 库（稳定、功能丰富）
    2. 失败时降级到 print 输出

  依赖：
    - winotify（第三方库）


┌─────────────────────────────────────────────────────────────────────────────┐
│  helper/scheduler.py - 定时任务模块                                          │
└─────────────────────────────────────────────────────────────────────────────┘
  功能：
    - 注册 Windows 任务计划程序（schtasks）
    - 设置每日定时提醒
    - 移除定时任务
    - 检查任务是否存在

  主要函数：
    - setup_reminder(time) : 注册每日提醒任务
    - remove_reminder()    : 移除提醒任务
    - check_reminder()     : 检查任务状态

  实现方式：
    - 调用 Windows schtasks.exe 命令行工具
    - 任务名称：HelperStudyReminder
    - 执行命令：python main.py notify send

  依赖：
    - subprocess（标准库）


================================================================================
                          使用流程示例
================================================================================

【完整使用流程】

1. 配置 API
   编辑 config.toml，填入 API 密钥和模型名称：
   [api]
   api_key = "your-api-key"
   base_url = ""  # 或兼容端点
   model = "claude-3-5-sonnet-20241022"

2. 创建学习目标
   python main.py goal add "背单词" --desc "考研 5500 词"
   python main.py goal add "刷算法" --desc "LeetCode 100 天"

3. 添加任务
   python main.py task add 1 "每天背 30 个新词"
   python main.py task add 1 "复习昨天的 50 个词"
   python main.py task add 2 "完成 2 道中等题"

4. 生成今日计划（AI）
   python main.py plan today
   # AI 会根据你的历史数据生成个性化计划

5. 打卡
   python main.py checkin single 1 --note "abandon, ability, able..." --duration 25
   # 或快速打卡
   python main.py checkin quick

6. 查看状态
   python main.py status
   # 显示今日进度、连续天数、各目标统计

7. 设置提醒
   python main.py notify setup
   # 每天 9:00 自动弹窗提醒

8. 生成报告
   python main.py report 7
   # AI 生成过去 7 天的学习总结


================================================================================
                          配置文件说明
================================================================================

config.toml 结构：

[api]
api_key = ""           # API 密钥（必填）
base_url = ""          # API 端点（留空=官方，或填兼容端点）
model = ""             # 模型名称（必填） 这里需要注意的是，请在官网上获取标准的模型标识符

[reminder]
time = "09:00"         # 每日提醒时间（HH:MM）
enabled = true         # 是否启用提醒

[display]
theme = "default"      # 终端主题（预留）

   python main.py task add 1 "测试任务"
   python main.py status

4. 设置提醒
   python main.py notify test
   python main.py notify setup
